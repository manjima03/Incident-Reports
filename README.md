# Incident Reports

This repository contains incident reports based on hands-on cybersecurity labs and attack simulations. Each report documents what happened, the evidence collected, how the activity was investigated, and the steps that could be taken to contain or prevent similar incidents.

The goal is to practise analysing security events, identifying suspicious activity, and documenting findings in a way that could help me learn the skills useful for a SOC analyst or incident response team.

## Reports

The repository includes investigations covering areas such as:

- **Brute Force Attacks** — Analysing repeated authentication failures and identifying potential unauthorised access attempts.
- **PowerShell-Based Attacks** — Investigating suspicious PowerShell activity and examining relevant Windows event logs.
- **Detection and Investigation** — Using available logs and SIEM queries to identify suspicious behaviour and support findings.

*Reports will be added as I work through more scenarios.*

## Tools and Technologies

- Microsoft Azure
- Microsoft Sentinel / Microsoft Defender
- Kusto Query Language (KQL)
- Windows Event Logs and PowerShell logging

## Approach

For each scenario, I aim to document:

- The incident summary and potential impact
- Relevant logs and evidence
- Detection methods and investigation findings
- Indicators of compromise, where applicable
- Recommended containment and remediation steps

## Disclaimer

These reports are based on controlled lab environments and simulated attack scenarios for learning purposes. They are intended to demonstrate my investigation process and practical understanding of security monitoring and incident response.
